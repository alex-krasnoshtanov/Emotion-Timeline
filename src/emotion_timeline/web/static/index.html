Emotion Timeline

A Russian-language video goes in, a per-scene emotion timeline comes out. Two models read every scene: one reads Russian directly, the other translates first. Scenes where they disagree are drawn faded, so you can see at a glance which parts to treat with caution.

… or drop one here.

The filter stops Whisper inventing words over silence. On a documentary with music under the narration it can drop real speech too, so turn it off if the transcript comes back with holes in it.

The first run downloads the models, which takes a few minutes.
